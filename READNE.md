# TaskPulse 🚀
A modern, feature-rich Progressive Web App (PWA) Todo list designed to help users organize their workflow efficiently.

### Features
- 💼 Categories & Priority Tags (Work, Personal, Study)
- 🔍 Live Search & Multi-criteria Filtering (All, Active, Completed)
- 📅 Due Dates tracking
- 💾 Data Persistence using Browser LocalStorage
- 📱 Installable as a PWA on mobile and desktop devices

### Tech Stack
- HTML5, Vanilla JavaScript (ES6+)
- Tailwind CSS
- PWA Service Workers & Web Manifest
